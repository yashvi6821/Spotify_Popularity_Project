# Spotify Song Popularity Analysis & Prediction

## Project Overview
This project analyzes Spotify song features and predicts song popularity using Machine Learning.

## Objectives
- Analyze Spotify song features.
- Visualize song popularity using graphs.
- Train and compare Machine Learning models.
- Identify important features affecting popularity prediction.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Machine Learning Models
- Linear Regression
- Random Forest Regressor

## Dataset
The dataset contains audio features such as danceability, energy, loudness, acousticness, tempo, duration, and popularity.

## Results
Random Forest performed better than Linear Regression in our current evaluation.

## Conclusion
This project uses data analysis and Machine Learning to study and predict Spotify song popularity.
